# Niketa Tembhare — Portfolio

Personal portfolio website for **Niketa Tembhare**, Software Developer & AI/ML Engineer.

## Tech Stack

- **Frontend:** React, TypeScript, Vite
- **Animations:** GSAP, ScrollTrigger
- **Icons & Analytics:** React Icons, Vercel Analytics

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```

## Deployment (Vercel)

Configured for zero-config deployment on Vercel via `vercel.json` (`npm run build` → `dist`).
